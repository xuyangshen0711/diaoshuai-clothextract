# 本厂产品

资料大类有四个固定值：本厂产品、网图趋势、品牌资料包、市调拍照。导入时每个文件都要选一个，同一批可以一键套用。抽出来的每张图继承该文件的大类。以前没有大类的记录归到「未分类」，不改审核版本号，进行中的审核不会因此冲突。另外三个大类只做归类，没有单独规则。

## 图片与款号

本厂产品可以直接上传 jpg / png / webp / gif / bmp / tif，也可以选文件夹或把文件夹拖进来，子目录里的图片都会带上。文件名去掉扩展名就是大货款号基码：`516083.jpg`、`516083 .JPG`、`s7529.jpg` 分别对应 `516083` 和 `S7529`。空格会去掉，字母会转成大写。文件名不要带客户后缀，`516083若宇.jpg` 不会自动并到 `516083`。

一个基码只保留一张在用图。再次上传同一款号会变成待审核的替换，即使文件内容和当前原图一样：图库仍显示旧图，审核里并排看新旧图。通过后新图替换旧图，旧图留在详情页历史里。选择「保留原图」会丢掉待确认的新图，并恢复替换前的审核状态。如果待确认的新图还没审，又上传一份字节相同的文件，这次会跳过，避免重复排队。

## 款式档案

在导入页下方单独上传 Excel，不走抽图。按表头名称读取：季节、大货款号、颜色、尺码、原料名称，以及针型、系列、一级品类。设计款号、客户全称和其他列忽略。空行和合计行（例如只有 `5`、`19`）跳过。表头不一定在第一行。

大货款号只在 `src/factory/codes.py` 解析：开头连续的字母和数字、且含有数字的部分是基码，剩下的是客户。没有后缀记为「本厂自有版本」。`633125*7` 的客户是 `*7`，不另取客户全称。同一大货款号再次导入会覆盖该行。颜色按逗号、中文逗号、顿号拆开，`+` 不拆（`上青+白` 是一个颜色）。色系先查对照表，再按关键字，对不上的归「其他」。尺码如 `95/S` 同时保留数字和字母。

有档案的本厂产品，图库和筛选里的品类用固定品类表，不直接显示档案原文。档案「一级品类」先查同义词：`长袖套衫` 归入 `上衣>套衫`，袖长长袖，面料针织；`背心` 归入 `上衣>背心/马甲`，袖长无袖。原文仍留在客户版本的一级品类列里。AI 若给出另一个品类（例如开衫），图库仍以档案为准，AI 标签只作参考。没有档案的本厂产品，以及网图、品牌资料包、市调拍照，用 AI 输出再走同一张同义词表；对不上的进「待归类」。本厂产品没有单独的面料信息时，面料默认针织。

## 销量

销量表列：款号、颜色、尺码、订单数量、订单金额。重复表头和底部合计行会跳过。存储键是大货款号 + 颜色 + 尺码 + 年份 + 周期。当前表没有年份，这两列为空，再次导入覆盖同一行，不会把 3411 件加成 6822。以后若按年导入，可以和这份空年份的数据并存。季节从款式档案带出。

导入结束后会列出「有档案但没有图片」和「有本厂图片但没有档案」的款号。已驳回的图片不算已有图片。

## 图库

主页在列表上方按资料大类、品类、季节、颜色筛选。品类先选一级，再选二级。本厂产品另有袖长筛选，面料放在「更多筛选」里。本厂产品的颜色按色系，任一客户版本含有该色系即算匹配，不再单列尺码、系列、针型、客户或另一套颜色筛选。搜索框可以找款号、客户名和原始颜色名。默认按最新导入排序，也可以按订单件数或金额排序。卡片显示款号、固定品类、色点和已售件数。详情页列出各客户版本、档案里的原始一级品类，以及按颜色、尺码的拆分。
