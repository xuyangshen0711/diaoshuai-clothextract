# 固定品类与同义词

品类不再随每次导入增长。所有资料都归入一张固定的两级表；袖长和面料是单独属性。

## 品类表

| 一级 | 二级 |
|------|------|
| 上衣 | 套衫、开衫、背心/马甲、T恤、衬衫、卫衣 |
| 外套 | 针织外套、大衣、夹克、西装、羽绒/棉服 |
| 连衣裙 | 无二级 |
| 半身裙 | 无二级 |
| 裤装 | 长裤、短裤、针织裤 |
| 套装 | 无二级 |
| 配饰 | 无二级 |

系统品类「待归类」用来接住对不上的叫法。它不能改名，也不能删除。

存进标签里的写法：有二级时是 `上衣>套衫`，没有二级时是 `连衣裙`。一级本身（例如 `外套`、`裤装`）也可以作为尚未选到二级时的标签，但在品类设置里指定归入目标时，有二级的一级必须选到二级。

袖长只有无袖、短袖、中袖、长袖。面料只有针织、梭织。看不清可以留空。本厂产品是针织厂，档案没有另给面料时，面料记为针织。

举例：

| 档案或口头叫法 | 固定品类 | 袖长 | 面料 |
|----------------|----------|------|------|
| 长袖套衫 | 上衣>套衫 | 长袖 | 针织 |
| 短袖套衫 | 上衣>套衫 | 短袖 | 针织 |
| 背心 | 上衣>背心/马甲 | 无袖 | 针织 |
| 长袖开衫 | 上衣>开衫 | 长袖 | 针织 |

档案原文字段仍原样保存，详情页客户版本表里的一级品类就是原文。

## 谁说了算

本厂产品只要款式档案里有一级品类，图库、筛选和审核列表都用这条原文映射后的结果，不用 AI 的品类。`516083` 的档案是长袖套衫，即使 AI 判成开衫，图库仍是上衣>套衫、长袖、针织。

没有档案时，用 AI 或模拟分类的品类，先查同义词表。OpenAI、DeepSeek 和模拟分类使用同一份枚举。模型若返回表外的词，先走同义词；还对不上就写成待归类，并记下原始叫法。不会因此新建品类。

## 同义词

初始对照覆盖常见叫法：针织开衫、毛衣、针织衫、套头衫、马甲、吊带、T恤、短T、裙子、连衣裙、阔腿裤、打底裤，以及样例档案里出现过的一级品类（长袖套衫、背心等）。完整种子在 `src/taxonomy.py` 的 `SEED_SYNONYMS`。

审核页可以按「待归类」筛选。选好一级和二级并归入后，原始叫法写入同义词表，下一次导入同样的叫法会自动归入。已经有明确对照的叫法（例如毛衣 → 套衫）不会被另一次误改覆盖。

导航「品类设置」可以查看和编辑品类表、同义词表。新增、改名、删除品类只在这里做。删除时如果还有图片或款式档案在用这个品类，会提示条数，并要求先把这些资料改归到别的品类。有二级的一级要先删掉二级。

## 旧数据

第一次打开数据库时，已有图片的品类按同义词表重写一次。对不上的变成待归类，原始叫法留在 `category_raw`。这次迁移不增加审核版本号，进行中的审核不会因此冲突。
