# 貂帅服装图片库：阿里云部署指南

给公司负责服务器的同事。应用是 FastAPI 后端加 Vue 3 前端。默认在开发电脑上用 SQLite 和本地文件夹；上云时同一套代码改用 RDS MySQL 和 OSS。搜索用的 FAISS 索引继续放在 ECS 硬盘上。AI 打标仍调用 OpenAI 或 DeepSeek，不使用阿里云 GPU。

机器规格按已确认的 **ecs.c8i.large（2 核 4G）** 来写。CLIP 模型吃内存，4G 建议加 2G 交换分区，避免第一次建索引时被系统杀掉。

## 1. 买什么、怎么放

| 产品 | 建议 | 作用 |
|------|------|------|
| ECS ecs.c8i.large | 和 RDS、OSS 放在同一个地域，系统用 Ubuntu 22.04 或 24.04 | 跑 API 和 Nginx |
| RDS MySQL 8.0 | 基础版即可，字符集 utf8mb4 | 款式、审核、档案、销量 |
| OSS | 标准存储，按量付费 | 图片 |
| CDN | 可选 | 让浏览器直接拉图片，不经过 ECS |

安全组只对办公网开放 **80** 和 **443**。**不要**把 8520（API）和 3306（MySQL）暴露到公网。RDS 白名单只填这台 ECS 的内网 IP。ECS 访问 RDS、OSS 都走内网地址。

## 2. 创建 RDS MySQL

1. 地域与 ECS 相同，引擎选 MySQL 8.0。
2. 创建数据库 `diaoshuai`，字符集 **utf8mb4**，排序规则 **utf8mb4_unicode_ci**。
3. 创建账号，只授予这个库的读写权限。密码记在密码本里，不要发到群里，也不要写进 Git。
4. 白名单加入 ECS 内网 IP。
5. 在 ECS 上用内网地址试连（把尖括号换成控制台里的值）：

```bash
sudo apt-get update
sudo apt-get install -y mysql-client
mysql -h <rds内网地址> -P 3306 -u <账号> -p diaoshuai
```

能进到 `mysql>` 就可以。内网地址一般是 `rm-xxxx.mysql.rds.aliyuncs.com` 那种，在 RDS 控制台「数据库连接」里看。

## 3. 创建 OSS

1. 新建 Bucket，地域与 ECS 相同，读写权限选**私有**。
2. 用 RAM 子账号的 AccessKey，只授予这个 Bucket 的读写。不要用主账号的 AccessKey。
3. ECS 和 OSS 同地域时，`.env` 里的 `OSS_ENDPOINT` 用内网，例如杭州：

```text
https://oss-cn-hangzhou-internal.aliyuncs.com
```

其他地域把 `cn-hangzhou` 换成控制台显示的地域。

4. 可选 CDN：添加加速域名，源站选这个 Bucket，回源用私有 Bucket 的回源鉴权。HTTPS 证书绑在 CDN 上。配好之后把域名写进 `OSS_CDN_BASE_URL`，例如 `https://img.example.com`（不要末尾斜杠）。不配 CDN 时，图片仍由网站的 `/api` 从 OSS 读出来再返回。

## 4. 安装系统依赖和代码

下面假设代码放在 `/opt/diaoshuai`，运行用户是 `diaoshuai`。

```bash
sudo apt-get install -y python3 python3-venv python3-dev build-essential nginx certbot python3-certbot-nginx git
sudo useradd --create-home --shell /bin/bash diaoshuai || true
sudo mkdir -p /opt/diaoshuai
sudo chown diaoshuai:diaoshuai /opt/diaoshuai

sudo -u diaoshuai -H bash -lc '
  cd /opt/diaoshuai
  git clone https://github.com/xuyangshen0711/diaoshuai-clothextract.git .
  python3 -m venv .venv
  . .venv/bin/activate
  pip install -U pip
  pip install -r requirements.txt
'
```

4G 内存建议先加交换分区，再装依赖、再建索引：

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

Node.js 用来构建前端。可以用 NodeSource 或系统里已有的 Node 20+：

```bash
sudo -u diaoshuai -H bash -lc '
  cd /opt/diaoshuai/frontend
  npm install
  npm run build
'
```

构建结果在 `/opt/diaoshuai/frontend/dist`。

## 5. 填写 .env

```bash
sudo -u diaoshuai cp /opt/diaoshuai/.env.example /opt/diaoshuai/.env
sudo chmod 600 /opt/diaoshuai/.env
sudo -u diaoshuai nano /opt/diaoshuai/.env
```

至少写上这些（全是占位符，换成控制台里的真实值）：

```bash
DATABASE_URL=mysql://app_user:密码@rm-xxxx.mysql.rds.aliyuncs.com:3306/diaoshuai?charset=utf8mb4

OSS_ENDPOINT=https://oss-cn-hangzhou-internal.aliyuncs.com
OSS_BUCKET=diaoshuai-images
OSS_ACCESS_KEY_ID=替换成子账号AccessKeyId
OSS_ACCESS_KEY_SECRET=替换成子账号AccessKeySecret
# OSS_CDN_BASE_URL=https://img.example.com

TAGGER_BACKEND=deepseek
DEEPSEEK_API_KEY=替换成打标密钥
EMBEDDING_BACKEND=clip
```

也可以不用 `DATABASE_URL`，改成 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD`、`MYSQL_DATABASE`。两套都写时以 `DATABASE_URL` 为准。

全部留空则仍是 SQLite 加本地图片，适合在自己电脑上开发。只填了一半，程序会报错退出，避免悄悄写到错误的地方。

`.env` 已经在 `.gitignore` 里。不要把它提交到仓库。

第一次在 MySQL 上建表：

```bash
sudo -u diaoshuai -H bash -lc 'cd /opt/diaoshuai && . .venv/bin/activate && python scripts/init_mysql.py'
```

表是 utf8mb4。程序启动时也会补建缺失的表，这条命令用来在开机前确认账号和网络是通的。

## 6. 从旧的 SQLite 把数据搬过来

开发电脑上如果已经有 `data/processed/catalog.sqlite3`，把整个 `data/` 目录拷到服务器同一位置（`/opt/diaoshuai/data`），然后在服务器上执行：

```bash
sudo -u diaoshuai -H bash -lc '
  cd /opt/diaoshuai
  . .venv/bin/activate
  python scripts/migrate_sqlite_to_mysql.py
  python scripts/upload_images_to_oss.py
'
```

`migrate_sqlite_to_mysql.py` 只复制数据库，不传图片。MySQL 里已经有记录时它会停下来；确认要覆盖才加 `--replace`。

`upload_images_to_oss.py` 把仍指向本地文件的图片传到 OSS，并把数据库里的路径改成 `oss://...`。默认保留本地文件。抽查网页能看图之后，再执行一次：

```bash
python scripts/upload_images_to_oss.py --delete-local
```

图片路径超过 512 个字符时迁移会停下来并说明原因。OSS 对象键用的是 `data/` 下面的相对路径，一般远短于这个限制。款号、颜色、尺码写入 MySQL 时各最长 128 个字符。

## 7. systemd 和 Nginx

单元文件在仓库的 `deploy/diaoshuai.service`。API 只监听 `127.0.0.1:8520`，并且 **只能有一个 worker**（导入进度记在这个进程里）。

```bash
sudo cp /opt/diaoshuai/deploy/diaoshuai.service /etc/systemd/system/diaoshuai.service
sudo systemctl daemon-reload
sudo systemctl enable --now diaoshuai
sudo systemctl status diaoshuai
curl -s http://127.0.0.1:8520/api/health
```

`/api/health` 里 `database` 应为 `mysql`，`storage` 应为 `oss`（配了 OSS 时）。

Nginx 示例在 `deploy/nginx.conf`。把域名和证书路径改掉：

```bash
sudo cp /opt/diaoshuai/deploy/nginx.conf /etc/nginx/sites-available/diaoshuai
sudo ln -s /etc/nginx/sites-available/diaoshuai /etc/nginx/sites-enabled/diaoshuai
sudo nginx -t && sudo systemctl reload nginx
```

有域名时申请证书（先让 80 端口能从公网访问这台机器）：

```bash
sudo certbot --nginx -d example.com
```

证书会自动续期。没有域名时，删掉示例里跳转到 443 的那段，只保留 `listen 80`，`root` 仍指向 `frontend/dist`，`/api/` 仍反代到 `127.0.0.1:8520`。

浏览器打开 `https://example.com`。导入、图库、搜索都走这个地址，前端请求的是相对路径 `/api`。

## 8. FAISS 索引

索引在 ECS 的 `data/processed/index`，不放进 RDS，也不放进 OSS。换机器或删掉索引之后，在服务器上重建：

```bash
sudo -u diaoshuai -H bash -lc '
  cd /opt/diaoshuai
  . .venv/bin/activate
  python scripts/prepare_local_search.py --index
'
```

这条命令会先准备 CLIP 权重（只下载模型，不上传服装图片），再为已审核和未审核图片各建一份索引。服务已经在跑、权重也已经在本机时，可以只重建索引：

```bash
curl -X POST http://127.0.0.1:8520/api/index/rebuild
```

审核之后，下一次搜索也会按需补索引。AI 打标不走这台机器上的模型，仍是 `.env` 里的 OpenAI 或 DeepSeek。

## 9. 备份

- **RDS**：打开自动备份，保留期按公司要求（例如 7 天）。需要手动导出时：

```bash
mysqldump -h <rds内网地址> -P 3306 -u <账号> -p \
  --single-transaction --set-gtid-purged=OFF \
  diaoshuai > /var/backups/diaoshuai-$(date +%F).sql
```

- **OSS**：在 Bucket 上打开版本控制，误删可以找回。重要的话再加一条跨区域复制。
- **FAISS 和本地缓存**可以不备份，按上一节重建。`data/raw` 里如果还留着原始 PDF / Excel，建议另行打包保存。

## 10. 以后从 main 更新

```bash
sudo -u diaoshuai -H bash -lc '
  cd /opt/diaoshuai
  git pull origin main
  . .venv/bin/activate
  pip install -r requirements.txt
  cd frontend && npm install && npm run build
'
sudo systemctl restart diaoshuai
sudo nginx -t && sudo systemctl reload nginx
```

更新前先看一眼 `/api/health`。数据库表会在服务启动时补齐，一般不用手工改表。如果这次更新带了新的迁移脚本，以该次说明为准。

## 11. 在自己电脑上怎么试

不配 `DATABASE_URL`、`MYSQL_*`、`OSS_*` 就是原来的本地模式：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
pytest
uvicorn api.main:app --host 127.0.0.1 --port 8520
```

另一个终端：

```bash
cd frontend && npm install && npm run dev
```

打开 <http://127.0.0.1:8518> 。想连自己电脑上的 MySQL 时，把 `MYSQL_HOST=127.0.0.1` 写进 `.env` 并先运行 `python scripts/init_mysql.py`。想试 OSS 时填写 `OSS_*`；没有阿里云账号就不要填，测试用的是本地磁盘。
